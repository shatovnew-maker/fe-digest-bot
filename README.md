# Бот-сводка: Дальний Восток в зарубежных СМИ

Каждое утро (около 7:50 по Владивостоку) присылает в Telegram подборку материалов, где упоминаются
Владивосток, Приморье или другие регионы Дальнего Востока России. В каждом пункте есть ссылка на статью,
цитата в оригинале и её перевод на русский.

Сначала идут издания из вашего списка, сгруппированные по странам. Ниже, отдельным блоком, — прочие
зарубежные издания. Российские СМИ и сайты-перепечатки не показываются.

Работает бесплатно на GitHub Actions, свой сервер не нужен.

---

## Настройка (примерно 10 минут)

### 1. Создайте бота в Telegram
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя и адрес бота (адрес должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохраните его.

### 2. Узнайте свой chat id
1. Напишите своему новому боту любое сообщение, например «привет».
2. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив свой токен.
3. Найдите в ответе фрагмент `"chat":{"id":123456789` — это число и есть **chat id**.

> Чтобы сводка приходила в канал: добавьте бота в канал администратором,
> а вместо chat id используйте адрес канала, например `@my_digest_channel`.

### 3. Загрузите бота на GitHub
1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите **New repository**, задайте имя (например, `fe-digest-bot`) и выберите **Private**.
3. В новом репозитории нажмите **Add file → Upload files** и перетащите в окно все файлы из архива.
   Папки `state` и `.github` должны сохранить свою структуру.
   - Если папка `.github` не загрузилась (на Mac она скрыта), нажмите **Add file → Create new file**,
     укажите путь `.github/workflows/digest.yml` и вставьте содержимое этого файла из архива.
4. Нажмите **Commit changes**.

### 4. Добавьте секреты
**Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `TELEGRAM_CHAT_ID` | chat id из шага 2 (или `@канал`) |
| `ANTHROPIC_API_KEY` | *необязательно*: ключ Claude API для более качественного перевода |

### 5. Проверьте запуск
1. Откройте вкладку **Actions**. Если GitHub попросит включить Actions, подтвердите.
2. Выберите **Ежедневная сводка → Run workflow**. Для первого раза можно указать `48` часов.
3. Через 2–5 минут сводка придёт в Telegram. Если запуск красный, откройте его и посмотрите журнал.

После этого бот будет запускаться сам каждый день.

## Как изменить настройки

Все настройки лежат в `config.yaml`. Его можно править прямо на GitHub (иконка карандаша):

- **`outlets`** — издания из вашего списка. Чтобы добавить издание, допишите строку с его доменом.
- **`languages → keywords`** — ключевые слова на английском, японском, корейском и китайском.
- **`include_other_sources: false`** — показывать только издания из списка.
- **`exclude_domains`** — сайты, которые никогда не попадают в сводку.
- **`lookback_hours`** — за сколько часов искать (по умолчанию 30, с запасом; повторы отсекаются).

Время отправки задаётся в `.github/workflows/digest.yml`, в строке `cron`. Время там указано в UTC:
Владивосток — это UTC+10, поэтому `47 21 * * *` означает 07:47 по Владивостоку.

## Как бот работает

1. Ищет ключевые слова в Google News и Bing News на английском, японском, корейском
   и китайском (упрощённом и традиционном) за последние ~30 часов.
2. Отбрасывает российские СМИ, перепечатки и то, что уже присылал раньше.
   Список отправленного хранится в `state/seen.json` и обновляется сам.
3. Открывает каждую статью и вырезает предложения с упоминанием. Если в тексте статьи
   упоминания нет (например, слово было только в рекламном блоке), материал отбрасывается.
4. Переводит заголовки и цитаты на русский: бесплатно через Google Translate
   или через Claude, если задан `ANTHROPIC_API_KEY`.
5. Отправляет сводку в Telegram. Если она длинная, разбивает на несколько сообщений.

## Ограничения

- **Платные статьи** (NYT, FT, WSJ, Bloomberg и др.) часто не открываются.
  Издания из списка всё равно показываются со ссылкой и пометкой ⚠️, но без цитаты.
- **Агрегаторы видят не всё.** Часть материалов китайских госСМИ (Xinhua, China Daily, Global Times)
  Google и Bing индексируют неполно, поэтому что-то может не попасть в сводку.
- **Пауза расписания.** GitHub приостанавливает расписание в репозитории, где 60 дней не было
  изменений. Бот сам сохраняет список отправленного, поэтому обычно этого не происходит.
  Если сводка перестала приходить, включите workflow во вкладке Actions.
- **Перевод.** Бесплатный перевод иногда путает японские и корейские имена.
  С ключом Claude API перевод заметно лучше и стоит центы в день.

## Запуск на своём компьютере (необязательно)

```bash
pip install -r requirements.txt
python bot.py --dry-run --hours 48     # показать сводку в консоли, ничего не отправляя
```
